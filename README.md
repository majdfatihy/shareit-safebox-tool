# 🔐 SafeBox DB Editor

> Free browser-based tool to restore SHAREit SafeBox lock credentials.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![HTML](https://img.shields.io/badge/HTML-only-orange.svg)]()
[![Arabic](https://img.shields.io/badge/lang-AR%20%2F%20EN-green.svg)]()

## Features

- ✅ Replace password, pattern lock, security Q&A in `safebox.db`
- ✅ Animated M-pattern visualizer
- ✅ File statistics (types, dates, deleted items)
- ✅ Numeric CAPTCHA before download
- ✅ Auto-detect language (AR/EN) + dark/light theme
- ✅ 100% local — file never leaves your browser
- ✅ Adsterra ads ready

## Usage

1. Extract `safebox.db` from your Android device
2. Open `safebox-editor.html` in any browser
3. Upload the file → Apply → Download

## Files

| File | Description |
|------|-------------|
| `safebox-editor.html` | Main tool (standalone) |
| `adsterra.js` | Ad loader (optional) |
| `sbx-k.js` | Encrypted keys (optional) |
